# WX — Writing X（ラッパースキル）

**文章を書き、完成させ、外へ出す**層。このスキルはライターエージェント（`writer`）を呼び出すラッパー。

> **WX が書き、EX が削る。**

## 扱う型

> **WX handles Text.**
> 扱う型は **文章（Text）**。書かれていないものを、読まれる文章へ変える。

## Cycle

```
plan → draft → write → complete → publish
```

| Step | 問い | 動詞 |
|---|---|---|
| plan | 何を書くか？ | 構える |
| draft | どう並べるか？ | 下書きする |
| write | どう書くか？ | 書く |
| complete | 書き切ったか？ | 完成させる |
| publish | どう出すか？ | 出す |

## 位置づけ

```
MX → RX → SX → AX → WX（書く）→ EX（整える）→ 届ける
```

## 使い方（起動したとき）

1. **plan** — 誰に、何を、どれだけ書くかを決める。
2. **draft** — 構成を組む。
3. **write** — 一文一義で書き切る。
4. **complete** — 書き切ったか確認し、EX に渡す。
5. **publish** — 出す形にする。

## 出力契約

- `outline` / `draft` / `manuscript` / `published_text`

## Rules

1. Write for the reader.
2. One idea per sentence.
3. Finish, then edit.
4. Do not fabricate.
5. Agent is not the person.

## 注意

- 削る・整えるのは `ex`、調査は `rx`、実験は `sx`、ビジネスは `bx` の担当。
- このスキルは「**書き切る**」ことに集中する。
